# 考研英语逐句精读 · 在线演示

将本目录的 `index.html`、`site.js` 和 `audio/` 按原结构上传到同一个静态站点。入口为 `index.html`，可以部署在站点根目录或子目录。

本地预览时，在解压目录运行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000/`。站点使用同源静态 MP3，支持字节范围请求的托管服务可以按需返回音频片段。

两篇完整样例为 2011 英二阅读 Text 1 和 2012 英二阅读 Text 2。示例词条预先整理，体验者可以核对原句后确认入本。生词本和另行导入的资料保存在当前浏览器，可使用站内导出功能备份。

首次打开只加载页面和脚本。试听、播放、拖动进度或打开手动打点时开始读取音频。手动打点时会加载完整文件以生成波形。
